1. โปรแกรมกราฟิกและนามสกุลไฟล์ต้นฉบับ

Ps

Adobe Photoshop

โปรแกรมจัดการภาพถ่ายและตกแต่งภาพแบบ Raster (Pixel)

ไฟล์ต้นฉบับ: .PSD
Ai

Adobe Illustrator

โปรแกรมวาดภาพและออกแบบลายเส้นแบบ Vector (ไม่แตกเมื่อขยาย)

ไฟล์ต้นฉบับ: .AI / .EPS
C

Canva

แพลตฟอร์มออกแบบกราฟิกออนไลน์ที่ใช้งานง่าย เหมาะสำหรับงานสำเร็จรูป

ส่งออกเป็น: .PNG / .JPG / .PDF

2. นามสกุลไฟล์ภาพที่ควรรู้จัก

.JPG / .JPEG

Joint Photographic Experts Group

  • บีบอัดไฟล์ได้เล็ก
  • ไม่มีพื้นหลังโปร่งใส
  • เหมาะสำหรับ: ภาพถ่ายทั่วไป, ใช้บนเว็บไซต์เพื่อโหลดเร็ว

.PNG

Portable Network Graphics

  • ความละเอียดสูง ไม่สูญเสียความคมชัด
  • รองรับพื้นหลังโปร่งใส (Transparent)
  • เหมาะสำหรับ: โลโก้, กราฟิกบนเว็บไซต์, แบนเนอร์

.GIF

Graphics Interchange Format

  • จำกัดสีแค่ 256 สี
  • รองรับภาพเคลื่อนไหว (Animation)
  • เหมาะสำหรับ: ภาพเคลื่อนไหวสั้นๆ, มีม (Meme)

.SVG

Scalable Vector Graphics

  • เป็นภาพแบบเวกเตอร์ เขียนด้วยโค้ด XML
  • ขยายใหญ่แค่ไหนก็ไม่แตก
  • เหมาะสำหรับ: ไอคอนบนเว็บไซต์, กราฟิก UI

เกร็ดความรู้ที่น่ารู้จากครูเจอาร์

💡 WebP คืออะไร? ปัจจุบันถ้าเราเซฟรูปจากเน็ต มักจะเจอไฟล์ .webp ซึ่งเป็นฟอร์แมตใหม่จาก Google ที่ทำให้ภาพชัดเท่า PNG หรือ JPG แต่ขนาดไฟล์เล็กกว่ามาก! สายทำเว็บแอปพลิเคชันต้องรู้จักไว้เลยครับ

💡 Raster vs Vector: ถ่ายรูปจากกล้อง = Raster (พิกเซลซูมแล้วแตก) | วาดโลโก้ใน Illustrator = Vector (ซูมเท่าตึกก็ไม่แตก)

💡 เคล็ดลับการเซฟงาน: หากนักเรียนต้องการนำรูปไปตัดต่อใน CapCut หรือใช้เป็น Assets ในการเขียนเว็บ (HTML/CSS/React) ควรเลือกใช้ไฟล์ .png แบบลบพื้นหลัง เพื่อให้จัดวางซ้อนกับองค์ประกอบอื่นได้เนียนที่สุดครับ
