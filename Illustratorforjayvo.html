Illustrator

ราชาแห่งงาน Vector ออกแบบโลโก้ วาดรูปทรงเรขาคณิต ขยายใหญ่แค่ไหนภาพก็ไม่แตก

Native: .AI / .EPS
C

Canva

แพลตฟอร์ม Cloud-based ที่คนรุ่นใหม่ต้องใช้ ทำงานไว จบงานได้ทั้งแบนเนอร์และพรีเซนต์

Export: .PNG / .JPG / .PDF

เจาะลึกนามสกุลไฟล์ภาพ

JPG

.JPG / .JPEG

Joint Photographic

  • ✓ บีบอัดไฟล์ได้เล็กมาก
  • ✗ ไม่รองรับพื้นหลังใส
  • 📌 เหมาะกับภาพถ่ายทั่วไปบนเว็บ
PNG

.PNG

Portable Network Graphics

  • ✓ รองรับพื้นหลังโปร่งใส (Alpha)
  • ✓ คงความคมชัดแม้เซฟซ้ำ
  • 📌 เหมาะกับโลโก้, ไอคอน, กราฟิกเว็บ
SVG

.SVG

Scalable Vector

  • ⭐ สร้างจากโค้ด (XML)
  • ⭐ ขยายระดับ 1000% ก็ไม่แตก
  • 📌 นิยมสูงสุดในการทำ UI เว็บไซต์ยุคใหม่
WEBP

.WebP

Next-Gen Format

  • ✓ ชัดเท่า PNG แต่ไฟล์เล็กกว่า
  • ✓ พัฒนาโดย Google
  • 📌 อนาคตของการทำเว็บโหลดไว

💡 เกร็ดความรู้แบบฉบับนักพัฒนา

ตัดต่อวีดีโอต้องใช้ไฟล์อะไร?

เวลาทำกราฟิกใน Photoshop หรือ Canva เพื่อเอาไปซ้อนใน CapCut ต้อง Export เป็น .PNG แบบ Transparent (ลบพื้นหลัง) เท่านั้น เพื่อไม่ให้มีขอบขาวติดไปในงานวีดีโอ

Dev ยุคใหม่เลือกใช้อะไร?

หากนักเรียนกำลังเขียนเว็บแอปพลิเคชัน (HTML/CSS) การใช้ .SVG สำหรับไอคอน โลโก้ และ .WebP สำหรับรูปภาพประกอบ จะช่วยให้คะแนนความเร็ว (PageSpeed) ของเว็บพุ่งกระฉูด!
