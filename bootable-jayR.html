💾 ส่วนที่ 1: การเตรียม USB ด้วย Rufus

การสร้าง USB Bootable คือก้าวแรกที่สำคัญ ส่วนนี้จะจำลองขั้นตอนการใช้งานโปรแกรม Rufus แบบเป็นลำดับขั้น เรียนรู้ว่าแต่ละจุดต้องตั้งค่าอย่างไร (เช่น GPT vs MBR) พร้อมอธิบายสิ่งที่ต้องเตรียมก่อนเริ่มงาน ให้คุณทำตามได้ทีละก้าวอย่างมั่นใจ

สิ่งที่ต้องเตรียม

  • 🔥
    USB Flash Drive ความจุขั้นต่ำ 8 GB (ข้อมูลจะถูกลบทั้งหมด)
  • 📀
    ไฟล์ ISO เช่น Windows 10/11 จากเว็บ Microsoft
  • 🛠
    โปรแกรม Rufus ดาวน์โหลดเวอร์ชันล่าสุดฟรี

⚙ ส่วนที่ 2: ตั้งค่า BIOS/UEFI และการบูต

หลังจากได้ USB แล้ว คุณต้องสั่งให้คอมพิวเตอร์บูตจาก USB แทนฮาร์ดดิสก์เดิม ส่วนนี้ออกแบบมาให้คุณค้นหาปุ่มลัด (Hotkey) ของคอมพิวเตอร์แต่ละแบรนด์ได้อย่างรวดเร็ว และตรวจสอบรายการตั้งค่าบังคับ (Checklist) ใน BIOS สำหรับฮาร์ดแวร์ยุคใหม่ (โดยเฉพาะการรองรับ Windows 11)

🔍 ค้นหาปุ่มเข้า BIOS / Boot Menu

กดปุ่มที่ระบุรัวๆ ทันทีที่เปิดเครื่องก่อนโลโก้ Windows จะขึ้น

📊 ส่วนที่ 3: เปรียบเทียบ UEFI vs Legacy BIOS

ทำไมเราถึงต้องตั้งค่าฮาร์ดแวร์ยุคใหม่ให้เป็น UEFI (GPT)? ส่วนนี้แสดงการเปรียบเทียบข้อมูลเชิงปริมาณ เพื่อให้เห็นความแตกต่างอย่างชัดเจนถึงขีดจำกัดของระบบเดิมเมื่อเทียบกับระบบใหม่ โดยเฉพาะเรื่องจำนวนพาร์ทิชันที่รองรับ

หัวข้อ UEFI (ปัจจุบัน) Legacy BIOS (เดิม)
รูปแบบ Partition GPT MBR
ความจุไดรฟ์สูงสุด 9.4 ZB (มหาศาล) 2 TB
จำนวน Partition ย่อย 128 พาร์ทิชัน 4 พาร์ทิชันหลัก
ความเร็วการบูต รวดเร็ว (Fast Boot) ช้ากว่า
รองรับระบบปฏิบัติการ 64-bit ปัจจุบัน/อนาคต ระบบเก่า (รวม 32-bit)

เปรียบเทียบการรองรับ Partition (GPT vs MBR)

ความยืดหยุ่นในการแบ่งไดรฟ์ของระบบปฏิบัติการ

🚨 ส่วนที่ 4: การแก้ไขปัญหาและเคล็ดลับ

รวบรวมปัญหาที่พบบ่อยระหว่างกระบวนการติดตั้งและวิธีแก้ไขที่ตรงจุด รวมถึงเคล็ดลับเพิ่มเติมในการจัดการดิสก์ เลือกเปิดดูหัวข้อที่ตรงกับปัญหาที่คุณกำลังพบ

💡 ข้อแนะนำเพิ่มเติมเมื่อบูตเข้า USB สำเร็จแล้ว

ในหน้าแบ่งพาร์ทิชัน (Where do you want to install Windows?) หากต้องการใช้ระบบ UEFI แบบสะอาดหมดจด ควรสำรองข้อมูลเดิมออกไปทั้งหมดก่อน จากนั้นเลือกลบพาร์ทิชันเก่าทั้งหมดด้วยการกด Delete จนเหลือเป็น Unallocated Space เพียงก้อนเดียว แล้วกด Next ระบบ Windows จะสร้างโครงสร้างพาร์ทิชัน GPT ใหม่อย่างถูกต้องเอง
